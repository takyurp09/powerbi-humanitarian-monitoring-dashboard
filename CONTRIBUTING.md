# Contributing

Thank you for your interest. This is a personal portfolio project, but issues and small pull requests are welcome.

- **Bugs and data issues:** open an issue using the bug report or data issue template.
- **Pull requests:** keep changes focused, run `make all` locally and make sure it passes before opening the PR; CI runs the same pipeline.
- **Data:** do not commit third-party files without an open licence (see [data/external/SOURCES.md](data/external/SOURCES.md)). Programme data in this repository are synthetic and must stay so.
- **Style:** British spelling in documentation; follow `.editorconfig`.
